# SuperKore

ชุดติดตั้งและอัปเดตของ SuperKore

## ติดตั้ง

1. โหลด **`SuperKore-<เวอร์ชัน>.exe`** จากหน้า [Releases](../../releases/latest) — โหลดไฟล์นี้ไฟล์เดียวพอ
2. วางไว้ในโฟลเดอร์ว่างๆ ที่อยากติดตั้ง (เช่น `D:\SuperKore`)
3. ดับเบิลคลิก แล้วกด `D` เพื่อให้โหลดชุด OpenKore มาให้อัตโนมัติ
4. ใส่คีย์ที่ได้จากผู้ขาย

หน้าจอโปรแกรมจะเปิดขึ้นมาเอง จัดการบอทได้จากตรงนั้น

> **อย่าปิดหน้าต่าง terminal ระหว่างใช้งาน** — ปิดเมื่อไหร่บอททุกตัวหยุดทันที
> ย่อเก็บไว้ได้ จะเลิกใช้ให้กด `Q`

## ไฟล์ใน release

| ไฟล์ | ต้องโหลดเองไหม |
|---|---|
| `SuperKore-<ver>.exe` | ใช่ — โหลดอันนี้อันเดียว |
| `SuperKore-App-<ver>.zip` | ไม่ต้อง ตัว exe โหลดเอง |
| `SuperKore-OpenKore-<ver>.zip` | ไม่ต้อง ตัว exe โหลดเอง |

## ต้องใช้อะไรบ้าง

- Windows 10 ขึ้นไป
- Google Chrome หรือ Microsoft Edge (สำหรับหน้าจอโปรแกรม)
- ไม่ต้องติดตั้ง Node.js หรืออะไรเพิ่ม
